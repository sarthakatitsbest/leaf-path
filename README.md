# EcoPulse AI 🌱

AI-driven sustainability platform focused on circular economy and waste-to-value.

## Problem

## Solution
EcoPulse AI tracks daily activities and provides AI-based sustainability insights.

- Plastic & carbon impact tracking
- AI-powered recommendations
- Simple dashboard
